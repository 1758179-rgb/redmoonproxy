# RedMoon Proxy

A red-themed web proxy with a DayDream X-inspired crimson moon aesthetic and DuckDuckGo default browsing.

## Files to keep in the repo root

- `index.html`
- `styles.css`
- `app.js`

## Browser image

To use the exact browser background image from your reference, save it as:

- `assets/redmoon-browser-bg.jpg`

Then the page will automatically apply it as the browser background.

## Run locally

Open `index.html` directly in a browser, or serve the repo with a local static server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## GitHub Pages

If you want it live via GitHub Pages:

1. Go to your repo settings.
2. Open **Pages**.
3. Select **Deploy from a branch**.
4. Choose **main** and the root folder.
5. Save.

Your site will be published at:

```text
https://<username>.github.io/redmoonproxy/
```
